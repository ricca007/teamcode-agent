# TeamCode Console · 设计说明

## 寄存器与锚点

- **Register**：`product-app`（登录后的工作台，目标是任务完成与日常使用）
- **锚点**：
  - **Linear**：232px 侧栏、36px 导航行、列表行 44px、状态 pill 20px、无阴影
  - **Primer**：diff 语义色、等宽字体对齐数字、文件路径截断
  - **Anthropic Console**：Agent 日志区保持透明，展示会话、级别与时间

## 物理场景

晚上在实验室的 14 寸笔记本上检查三个模块的进度，终端和浏览器并排。环境光偏暗但屏幕亮度正常，所以选择浅色高密度界面，避免深色与青色强调的常见 AI 审美。

| --- | --- |
| 背景 | `oklch(0.985 0.004 75)` 暖白 |

| 正文 | `oklch(0.22 0.012 75)` |
| 次要文字 | `oklch(0.47 0.012 75)` |
| 边框 | `oklch(0.9 0.006 75)` / 强边框 `oklch(0.82 0.008 75)` |

| 间距 | 4 / 8 / 12 / 16 / 24 / 32px |
| 圆角 | 4px 输入与按钮，6px 面板，999px 计数胶囊 |
| 层级 | 不使用阴影，靠背景对比与 1px 边框 |

| 可访问性 | 文字对比 ≥ 4.5:1，焦点环 2px 强调色，日志区 `role="log"` |

## 组件状态

- 按钮：default / hover / active / focus-visible / disabled / loading（刷新图标旋转）
- 任务卡：default / hover（边框加深，无位移）
- 会话行：default / hover / active（琥珀浅底）
- 接口行：default / hover / active
- 列表：loading 骨架 / empty / error banner + 重试
- 日志：自动滚动开关、空态、断线状态
- diff：展开/收起、增删配色、行内元数据

## 响应式

- `> 1100px`：四列看板
- `≤ 1100px`：两列
- `≤ 980px`：会话与接口分栏改为单列
- `≤ 900px`：侧栏变为顶部横向导航
- `≤ 720px`：单列看板
