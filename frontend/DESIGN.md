# MVP workbench design

The page follows the classroom order: requirements, task board, Agent workspace and interfaces. Status counters provide context. Logs, diffs and tests share workspace tabs. Connection/invitation forms are collapsed.

Columns stack on narrow screens; long module paths wrap. System fonts and CSS avoid runtime font downloads. Disabled controls reflect roles and execution state; backend checks are authoritative. Offline samples have a banner and disable changes.

A/B/C selection is a classroom shortcut, not a login screen. Full-console design notes remain in the separate `teamcode-agent` checkout.
